# SPA 소개

## SPA 란?

**SPA** 는 페이지 새로고침 없이 데이터를 동적으로 업데이트하여 앱과 같은 경험을 제공하는 웹 애플리케이션입니다.

- **트래픽 절감**: 페이지 이동 시 서버로 요청하지 않으므로 HTTP 요청이 줄어듭니다.
- **사용성 향상**: 빠른 페이지 전환과 부드러운 인터랙션이 가능합니다.
- **데이터 관리**: 클라이언트 측에서 데이터를 효율적으로 관리할 수 있습니다.

---

## React 의 장점

### 1. **컴포넌트 기반 개발**

- 작은 기능 단위 (컴포넌트) 로 앱을 구성할 수 있어 유지보수가 용이합니다.
- 컴포넌트를 재사용하고 조합하여 유연하게 애플리케이션을 확장할 수 있습니다.

### 2. **반응형 업데이트**

- 상태 (State) 변경에 따라 인터페이스 가 자동으로 업데이트됩니다.
- 가상 DOM 을 사용하여 효율적인 렌더링을 수행합니다.

### 3. **명확한 데이터 흐름**

- `prop drilling` 을 통해 데이터 흐름이 명확하게 관리됩니다.
- Context API 와 Redux 등 다양한 스토어 라이브러리로 복잡한 상태 관리도 가능합니다.

### 4. **대규모 애플리케이션 지원**

- `React Router` 등 생태계가 풍부하여 복잡한 라우팅을 지원해줍니다.
- `TypeScript` 와의 호환성이 높아 코드 품질을 보장할 수 있습니다.

### 5. **커뮤니티 및 도구 생태계**

- 다양한 라이브러리 (`Next.js`, `React Query`, `Redux Toolkit` 등) 가 풍부합니다.
- 대규모 개발자를 지원해줌으로 학습 자료와 튜토리얼이 풍부합니다.

### 6. **모놀리식 코드 관리**

- 프로젝트에 많은 코드 및 컴포넌트 포함할 때 코드 관리는 더 수월합니다.
- `npm install` 을 통해 의존성을 간단히 관리할 수 있습니다.

---

## SPA 와 React 의 결합

현대 웹 개발에서는 React 를 중심으로 다양한 라이브러리 (`Next.js`, `Vite`, `Create React App` 등) 를 사용하여 SPA 를 구축하고 있습니다.

### React 의 주요 특징

- **제네릭 타입 시스템**: 컴포넌트 간 데이터 흐름을 명확하게 표현
- **이벤트 시스템**: 사용자 상호작용 처리
- **상태 관리**: `useState`, `useReducer`, `Context API` 등
- **라이프사이클**: `useEffect` 를 통해 외부 변경사항 대응

---

## 요약

SPA 는 페이지 전환 시 서버로 요청하지 않는 방식이며, React 는 SPA 의 중심이 되는 프레임워크로 컴포넌트 기반, 반응형 업데이트, 명확한 데이터 흐름 등의 장점을 제공합니다.
